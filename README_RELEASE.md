## Downloads & Installation

Official pre-compiled binaries are ready for 64-bit Windows environments.

| Distribution Package | Target Architecture | Description | Download Link |
|---|---|---|---|
| **Windows Installer** (`.exe`) | Windows 10 / 11 (x64) | Full setup wizard with desktop shortcut, Start Menu entry, and uninstaller. | [Download Setup (.exe)](https://github.com/NomanRafique01/ToolCEO/releases/latest/download/ToolCEO-Setup-1.0.0.exe) |
| **Portable Archive** (`.zip`) | Windows 10 / 11 (x64) | Standalone portable executable. Extract and run without administrative privileges. | [Download Portable (.zip)](https://github.com/NomanRafique01/ToolCEO/releases/latest/download/ToolCEO-Setup-1.0.0.zip) |

### Installation Instructions

1. **Installer Version (`.exe`)**:
   - Download `ToolCEO-Setup-1.0.0.exe`.
   - Run the executable and follow the setup wizard.
   - Launch ToolCEO from your Start Menu or desktop shortcut.

2. **Portable Version (`.zip`)**:
   - Download `ToolCEO-Setup-1.0.0.zip`.
   - Extract the contents to any local folder (e.g. `C:\ToolCEO`).
   - Run `ToolCEO.exe` directly. No administrative privileges required.

### System Requirements

- **Operating System:** Windows 10 or Windows 11 (64-bit)
- **Processor:** Intel Core i3 / AMD Ryzen 3 or equivalent
- **Memory (RAM):** 4 GB minimum (8 GB recommended for large batch jobs)
- **Disk Space:** 600 MB free storage for core application and local processing engines
- **Network:** None required. Operates completely disconnected from the internet

## Security & Privacy Commitment

ToolCEO is engineered with a strict **Privacy-First Architecture**:
- **Zero Cloud Footprint:** No files or telemetry packets are transmitted over the internet.
- **Local Storage Bound:** All temporary files are processed inside isolated local directories and removed after conversion.
- **Air-Gapped Compatible:** Operates seamlessly on disconnected, confidential, and enterprise air-gapped computers.
